# Cryptocube

Учебная песочница по криптовалютам: шесть «кубиков» по шесть граней, в каждой грани одно практическое задание с ловушкой.
Все деньги, адреса, seed-фразы и сети ненастоящие, ничего не подключается к реальным блокчейнам.

| Кубик | Тема |
|---|---|
| 1 | Первый кошелёк: seed-фраза, переводы, комиссии, обозреватель, восстановление |
| 2 | Безопасность: фишинг, подмена адреса, фейковая поддержка, опасные подписи, аппаратный кошелёк |
| 3 | Биржи: KYC и 2FA, стакан и ордера, сети и memo, первый DEX, проскальзывание и MEV |
| 4 | Мультичейн и приватность: L2 и газ, мосты, не-EVM сети, Monero, Zcash |
| 5 | DeFi: стейкинг, ликвидный стейкинг, кредитование, пулы и фарминг, стейблкоины |
| 6 | Смарт-контракты: чтение кода, calldata, отзыв разрешений, мультиподпись, свой ERC-20, финал в Sepolia |

## Запуск

Это один статический файл `index.html` без сборки и зависимостей. Откройте его в браузере или разверните на любом статическом хостинге.
Прогресс хранится в `localStorage` браузера.

## Правовые рамки

Платформа учебная: она не принимает и не хранит криптовалюту, не проводит обмен и не даёт инвестиционных рекомендаций.
Сценарии с оплатой услуг разыграны в учебной юрисдикции; в РФ оплата товаров и услуг криптовалютой запрещена (259-ФЗ).

## Справочник и подсказки

- Кнопки «Словарь» и «Библиотека» в шапке открывают справочник: 55 терминов по кубикам с поиском и подборку проверенных внешних ресурсов.
- Термины в тексте заданий подчёркнуты пунктиром: при наведении, фокусе с клавиатуры или касании появляется короткое объяснение.

## ИИ-помощник

Кнопка «Спросить ИИ» открывает чат. Помощник знает, на какой грани находится ученик, отвечает по-русски, не даёт инвестиционных советов и не принимает seed-фразы.

Запросы идут через серверную функцию `api/ask.js` на Vercel, поэтому ключ API не попадает в браузер. Функция работает с любым OpenAI-совместимым API.
Без ключа (и при открытии файла локально) помощник отвечает в офлайн-режиме из словаря и подсказок к текущей грани.

Переменные окружения в Vercel (Project → Settings → Environment Variables):

| Переменная | Значение |
|---|---|
| `AI_API_KEY` | ключ провайдера, обязательно |
| `AI_BASE_URL` | по умолчанию `https://generativelanguage.googleapis.com/v1beta/openai` (Google Gemini) |
| `AI_MODEL` | по умолчанию `gemini-2.5-flash` |

Бесплатные варианты:

- **Google Gemini** (по умолчанию): ключ в Google AI Studio, достаточно только `AI_API_KEY`. Хорошо отвечает по-русски. На бесплатном тарифе Google может использовать запросы для улучшения своих моделей.
- **Groq**: `AI_BASE_URL=https://api.groq.com/openai/v1`, модель из их списка, например `llama-3.3-70b-versatile`. Очень быстрый.
- **OpenRouter**: `AI_BASE_URL=https://openrouter.ai/api/v1`, модели с суффиксом `:free`. Небольшой дневной лимит.

После добавления переменных сделайте Redeploy. Функция ограничивает частоту: не больше 20 вопросов за 10 минут с одного IP.
