# Cryptocube

Учебная песочница по криптовалютам: шесть «кубиков» по шесть граней, в каждой грани одно практическое задание с ловушкой.
Все деньги, адреса, seed-фразы и сети ненастоящие, ничего не подключается к реальным блокчейнам.

| Кубик | Тема |
|---|---|
| 1 | Первый кошелёк: seed-фраза, переводы, комиссии, обозреватель, восстановление |
| 2 | Безопасность: фишинг, подмена адреса, фейковая поддержка, опасные подписи, аппаратный кошелёк |
| 3 | Биржи: KYC и 2FA, стакан и ордера, сети и memo, первый DEX, проскальзывание и MEV |
| 4 | Мультичейн и приватность: L2 и газ, мосты, не-EVM сети, Monero, Zcash |
| 5 | DeFi: стейкинг, ликвидный стейкинг, кредитование, пулы и фарминг, стейблкоины |
| 6 | Смарт-контракты: чтение кода, calldata, отзыв разрешений, мультиподпись, свой ERC-20, финал в Sepolia |

## Запуск

Это один статический файл `index.html` без сборки и зависимостей. Откройте его в браузере или разверните на любом статическом хостинге.
Прогресс хранится в `localStorage` браузера.

## Правовые рамки

Платформа учебная: она не принимает и не хранит криптовалюту, не проводит обмен и не даёт инвестиционных рекомендаций.
Сценарии с оплатой услуг разыграны в учебной юрисдикции; в РФ оплата товаров и услуг криптовалютой запрещена (259-ФЗ).
